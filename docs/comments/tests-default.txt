[1] Evaluation-time invariants for the NixOS configuration.
    from tests/default.nix (lines at time of move: 5-11)
----------------------------------------------------------------------
Evaluation-time invariants for the NixOS configuration.

These run under `nix flake check` (including `--no-build`) because a failed
invariant makes `checks.<system>.config-invariants` throw during evaluation.
They guard the failure classes that previously only showed up on the real
machine: emergency mode at boot, an over-privileged guest, and a dead DNS
setup.
