Neodots - comments moved out of source files: boot
======================================================================

These notes were long enough to bury the code they describe, so they live
here. Each section is referenced from the source file by number.

[1] ESP size and generation limit
    from modules/system/boot.nix
----------------------------------------------------------------------
The ESP (nvme0n1p1) is shared between Windows and NixOS and is usually small.
Every kept generation stores a kernel and an initrd on it (linuxPackages_latest
makes them large). Without a limit the ESP eventually fills, the bootloader
install fails halfway, and the default boot entry keeps pointing at an older
generation whose closure nix.gc has already deleted. That is exactly what
"Failed to start Find NixOS closure" means. Tune the limit with
neodots.boot.configurationLimit in hosts/nixos/machine.nix.


[2] systemd-boot editor disabled
    from modules/system/boot.nix
----------------------------------------------------------------------
The machine has a passwordless guest account. Letting anyone edit the kernel
command line at the boot menu (init=/bin/sh) would give them a root shell, so
the editor is disabled. Recovery goes through an older generation in the menu
or a live USB instead.
